# Amin Live TV v3.9.1

This release finishes the home-screen work from 3.9.0 and takes its visual direction from Amin Player 1.37. The main menu stays on screen while browsing the home sections. A large Persian landscape, gold details, and clear focus borders give the home screen a cinematic feel. The seven saved themes remain available.

- **پخش زنده**: Iranian channels, world news, sport, and films/entertainment.
- **فیلم و مستند**: films, documentary/nature tabs, science/space, and other interests.
- **سریال‌ها**: Iranian and international series. Continue Watching shows the saved Iranian episode on the home screen.
- **تنظیمات**: themes, separate intro/sound switches, and the installed version number.

The new short intro pours gold into the TV mark and reveals the name with Amin Player's strike sound. Any remote key skips it. It respects the TV's reduced-motion setting and stops its sound when skipped or when leaving the app. The intro shares the activity's renderer, avoiding the additional graphics surface that exhausted graphics resources during repeated tests on the Xiaomi box. Focus returns to the home action when the intro ends.

The existing update notice appears above the home artwork when a newer signed APK is available. Downloads are automatic; installation still needs OK and Android's confirmation. The release keeps package `com.enigma.aminlivetv`, uses version code 17 and the existing signing key. Saved viewing data, documentary rounds, catalogue IDs and subtitle rules keep their existing formats. The channel catalogue is unchanged.

## Verification

See [the 3.9.1 verification record](../verification-3.9.1.md) for the build, emulator, and physical-device results and their limits.

The main Xiaomi installation was deliberately left at **3.8.0** for the owner's in-app update check. Device tests used the separate **Amin TV Preview** package. Only the signed production APK is attached to this release.
