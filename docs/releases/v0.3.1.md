Amin Live TV 0.3.1 updates itself from GitHub.

- **In-app updates:** when a newer release is published, the app downloads it in the background. It installs the download only if it is Amin Live TV, newer, and signed with the same key. The home button then says «نسخهٔ … آماده است · برای نصب OK را بزنید».
- **How to install:** press OK on that button, then Right and OK on **Install**. The first time only, Android asks to allow installs from Amin Live TV: choose **Settings**, turn it on, and reopen the app.
- **After an update:** the TV returns to its home screen. Open Amin Live TV again from there, because Android 11 doesn't let apps reopen themselves.

Tested on the Android TV emulator (Google TV, Android 11) with local test releases. On the Xiaomi box, 0.3.0 was installed over 0.2.2 and BBC Persian played through the YouTube app. Nothing else is new in this release. Install 0.3.1 manually one last time; later versions arrive through the app.
