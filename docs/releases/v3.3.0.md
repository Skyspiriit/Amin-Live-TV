Amin Live TV 3.3 fixes in-app updates on TVs where Android's install permission went to the wrong copy of the app.

- **Version number:** the app now shows v3.3 (it follows 0.3.3). The release tag is `v3.3.0` so that 0.3.3 finds it.
- **Install permission:** before installing an update, the app checks whether it may install apps. If not, it opens the **Install unknown apps** page, and when you come back with the switch on, the install confirmation appears by itself. If the switch is still off, a message explains what to do.
- **Known TV problem:** on some Xiaomi boxes, a hidden work profile holds a second copy of the app. TV Settings then lists only that copy, so the right switch can't be turned on. Removing that second copy fixes it (see UPDATE-PERMISSION-3.3.md).

Tested on the Android TV emulator (Google TV, Android 11) with the same work-profile setup as the box: update from 3.3 to a newer test build, with viewing history kept.
