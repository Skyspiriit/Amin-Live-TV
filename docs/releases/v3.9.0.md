# Amin Live TV v3.9.0

Amin Live TV now looks like Amin Player. It has a gold TV mark on the launcher icon and banner. It opens with the same short startup intro and sound, which any key skips. A top menu holds «پخش زنده», «فیلم و مستند», «سریال‌ها» and «تنظیمات». «تنظیمات» chooses the theme and can turn the intro or its sound off. «سینمای طلایی», Amin Player's charcoal and gold, is the new default. A TV that already chose a theme keeps it.

The home screen is simpler. Below the menu, «ادامهٔ تماشا» resumes the last station and the latest series episode. Three sections follow:

- **پخش زنده**: شبکه‌های ایرانی، اخبار جهان، ورزش، فیلم و سرگرمی
- **فیلم و مستند**: فیلم سینمایی، مستند و طبیعت، علم و فضا، موضوعات دیگر
- **سریال‌ها**: سریال ایرانی، سریال خارجی

The home screen has 10 large tiles instead of 15 plus a banner. «مستند و طبیعت» opens a grid with tabs for مستند، حیات وحش and طبیعت. «موضوعات دیگر» does the same for مافیا و مسابقه، سینما و فانتزی، دنیای خودرو، شطرنج and آیین و مداحی. Press Up from the grid to reach the tabs. The grid reopens on the tab used last. Back always returns to the tile you came from.

Nothing was removed. Channels, programmes, series, saved positions, themes and the update button are unchanged.

## Checks

GitHub Actions built the app, ran all unit tests and ran lint. All passed.

An Android TV emulator (Android 11) upgraded a 3.8.0 build with saved viewing data to 3.9.0 in place, then used only remote keys. The checks covered:
- the intro
- the top menu
- section order and focus
- all tiles and tabs
- Back from every screen
- resuming the saved station and series episode
- the settings switches and theme persistence after a restart

The saved station and series bookmark survived the upgrade. These tests ran on the emulator, not the Xiaomi box. They used debug builds, not the signed release.
