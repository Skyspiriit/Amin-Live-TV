# Amin Live TV v3.9.0

The home screen is simpler. Below the header, «ادامهٔ تماشا» resumes the last station and the latest series episode. Three sections follow:

- **پخش زنده**: شبکه‌های ایرانی، اخبار جهان، ورزش، فیلم و سرگرمی
- **فیلم و مستند**: فیلم سینمایی، مستند و طبیعت، علم و فضا، موضوعات دیگر
- **سریال‌ها**: سریال ایرانی، سریال خارجی

The home screen has 10 large tiles instead of 15 plus a banner. «مستند و طبیعت» opens a grid with tabs for مستند، حیات وحش and طبیعت. «موضوعات دیگر» does the same for مافیا و مسابقه، سینما و فانتزی، دنیای خودرو، شطرنج and آیین و مداحی. Press Up from the grid to reach the tabs. The grid reopens on the tab used last. Back always returns to the tile you came from.

Nothing was removed. Channels, programmes, series, saved positions, themes and the update button are unchanged.

## Turkish series

«سریال خارجی» opens the international series collection (formerly «سریال کامل»). The app can now show Turkish series under «سریال ترکی», in the same episode screens as the Iranian series, with Persian subtitles requested automatically. No Turkish series is in the catalogue yet. Each one must first pass the playback checks from Portugal. It can then be added through a catalogue update, without a new app version.

## Checks

GitHub Actions built the app, ran all unit tests, including new tests for the Turkish library and the subtitle choices, and ran lint. All passed.

An Android TV emulator (Android 11) upgraded a 3.8.0 build with saved viewing data to 3.9.0 in place, then used only remote keys. The checks covered:
- section order and focus
- all 10 tiles and the tabs
- Back from every screen
- resuming the saved station and series episode
- theme persistence after a restart

The saved station, series bookmark and theme survived the upgrade. These tests ran on the emulator, not the Xiaomi box. They used debug builds, not the signed release.
