# Fantasy home artwork

The home screen uses an illustrated Persian garden, a floating palace and a desert palace. Each of the six saved colour palettes selects one setting and retains its existing preference key. The chooser previews the scene and palette name. Artwork is bundled so the home screen works offline.

The layout follows Android TV guidance for readable text over imagery, predictable D-pad paths and focused controls. The artwork is decorative and is excluded from accessibility focus. Category names, playback actions and progress are native text. [TV layouts](https://developer.android.com/design/ui/tv/guides/styles/layouts) · [TV cards](https://developer.android.com/design/ui/tv/guides/components/cards) · [D-pad navigation](https://developer.android.com/training/tv/get-started/navigation)

## Assets

Generated with the built-in image-generation tool. The app bundles JPEG encodings of the three generated images.

- `app/src/main/res/drawable-nodpi/fantasy_garden.jpg`
- `app/src/main/res/drawable-nodpi/fantasy_palace.jpg`
- `app/src/main/res/drawable-nodpi/fantasy_desert.jpg`
